# Fonts for OK synthesis

Drop `.ttf`/`.otf`/`.ttc` font files here. The `ml_ok_synthesize` service
filters them by stroke ratio (default 0.10–0.20 — medium-bold sans/mono
suitable for printed datecodes).

## Recommended fonts (industrial datecode style)
- Arial Bold / Arial Narrow Bold
- Tahoma Bold / Verdana Bold
- Courier New Bold / DIN Alternate Bold
- DejaVu Sans Mono Bold / Liberation Sans Bold

If a font doesn't render on your platform, the loader will silently skip it.
