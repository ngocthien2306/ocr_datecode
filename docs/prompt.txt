  📝 Luồng hoạt động chi tiết

  1️⃣ Connect Camera

  FE → BE (POST /cameras/{serial}/connect)
    → BE → WebSocket → CameraManagement
      → CameraManager.add_camera(serial)
        → spawn Camera subprocess
          → Camera opens Basler, writes to shared_memory
    ← CameraManagement ← WebSocket ← {status: "connected"}
  ← BE ← {success: true}

  2️⃣ Load Recipe

  FE → BE (POST /recipes/{id}/load)
    → BE → WebSocket → CameraManagement
      → {event: "load_recipe", data: {...full recipe JSON...}}
        → CameraManager updates all cameras in recipe
          → Each Camera:
            - Update exposure/gain/trigger_config
            - Load templates
            - Initialize SuperPointMatcherTRT
            - Start hardware trigger loop
    ← BE ← {success: true, recipe_id: "xxx"}
  FE → redirect to /inference page

  3️⃣ Live Camera / Capture

  FE → BE (GET /cameras/{serial}/live or /capture)
    → BE → SharedMemoryService.read_frame(serial)
      → Read from shared_memory: camera_{serial}
      → Decode: frame_bytes → numpy → JPEG encode
    ← BE ← JPEG image
  ← FE display

  4️⃣ Trigger Event (Hardware DI)

  Hardware DI: 0→1 (RisingEdge)
    → Camera detects trigger
      → Capture frame → write shared_memory
      → Run SuperPointMatcherTRT.match()
      → result = {success, confidence, bboxes, pass/fail}
      → Save result to temp (image + JSON)
      → CameraManagement → WebSocket → BE
        → {event: "inference_result", data: result}
        → BE saves to DB + moves image to storage
        → BE → SocketIO → FE
          → {inference_result: ...}
  ← FE updates UI (show result, pass/fail status)

  5️⃣ Disconnect Camera

  FE → BE (POST /cameras/{serial}/disconnect)
    → BE → WebSocket → CameraManagement
      → CameraManager.remove_camera(serial)
        → Kill Camera subprocess
        → Cleanup shared_memory
    ← BE ← {success: true}
