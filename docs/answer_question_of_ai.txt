Vấn đề hiện tại:
  - Connect camera qua subprocess Python script → khó debug/kiểm soát
  - Config qua JSON file → bất tiện, nhiều hạn chế

  Solution đề xuất:
  - Socket giữa BE (FastAPI) ↔ AI Service
  - CameraManagement quản lý nhiều Camera
  - Shared memory để share frame
  - Trigger qua chân DI (0→1, 1→0, hoặc cả hai) → chụp N frame → inference với SuperPointMatcherTRT

Tôi cần làm rõ: BE sẽ giao tiếp với CameraManagement, còn AI Service chỉ là 1 phần nhỏ khi người dùng load recipe để ta inferece các chức năng AI
