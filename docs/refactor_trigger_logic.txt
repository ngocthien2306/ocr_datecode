Camera Settings:
Exposure Time (μs)

Trigger Configuration:

Trigger Mode:
Continuous (Free-running)
Software Trigger
Hardware Trigger (I/O)

Tôi cần làm rõ: Software Trigger là dùng "Digital Input (DI) Number" để nhận input sau đó camera sẽ software trigger để lấy frame, các trigger frame khi nhận input 
0->1 Rising Edge
1->0 Falling Edge
Any Edge (Both)

Hardware Trigger là trên camera sẽ có các line để ta đấu dây vào, sẽ tự động trả frame khi có event trigger (điều này có đúng không? hãy trả lời cho tôi)

Với mode Software Trigger hiện tại đang để trống, chưa có config chân DI, Trigger Activation và Trigger Selector 

theo phân tích trên thì khi select Hardware Trigger thì không cần Digital Input (DI) Number đúng không? chỉ cần select Trigger Source (Line0, Line1, ...)

về phần software trigger, camera nào tôi cũng sẽ set chung 1 chân DI để đảm bảo khi chân đó (0->1), (1->0) or both thì camera nào cũng sẽ software trigger để lấy frame cùng thời điểm (cố gắng chụp cùng lúc)

sau khi chụp cùng lúc về phần logic inference để dùng tất cả các frame của các camera để xử lý logic (logic này tôi sẽ implement sau), trước mắt là dùng SuperPointMatcherTRT để inference trước, về sau sẽ có logic OCR các vùng mà SuperPointMatcherTRT tìm ra, tuy nhiên để to do sẽ implement sau

vì vậy hãy thiết kế lại flow của camera và camera managemnt, sau đó chỉnh sửa trên UI và BE về các field cần lưu 

ngoài ra khi có software hoặc hardware trigger thì cứ gửi frame đó và shared memory giống như continuous để lúc nào trong đó cũng có frame mới nhất dù có mode nào đi chăng nữa
